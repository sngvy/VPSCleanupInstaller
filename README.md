# VPSCleanupInstaller

**VPSCleanupInstaller — это скрипт, который автоматически настроит и выполнит уборку VPS по расписанию.**

# Использование

**`bash <(curl -Ls https://raw.githubusercontent.com/sngvy/VPSCleanupInstaller/refs/heads/main/VPSCleanupInstaller.sh)`**

# Технические детали

- **Расписание: Может работать ежедневно, еженедельно и ежемесячно в назначенное время.**
- **Опционально: Может удалять неиспользуемые Docker-контейнеры и ядра Linux.**
- **Совместимость: Поддерживает Ubuntu и RHEL-based дистрибутивы.**
